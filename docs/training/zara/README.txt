Practice files for the "Cyclone Zara" exercise (fictional cyclone, for training only).

Made with the RAP repository's own scripts, from the template with these intensities set:
  Central Malekula 4, North Ambrym 4, North West Malekula 3,
  North East Malekula 3, South West Malekula 2. All other councils 0.

  Ex_hazard_areas.csv                 the input RAP reads (Step 1)
  area_councils_intensity.geojson     Step 3: export_intensity_geojson.R
  area_councils_intensity.pmtiles     Step 3: export_intensity_pmtiles.sh (layer name: councils)

Use the .pmtiles and .geojson in the New event block of the import page (Step 5)
if tippecanoe is not installed. Use a practice event name, not a real one.
